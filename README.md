# Йетя — мессенджер на GitHub Pages + Supabase

Веб-приложение (PWA): открывается по ссылке на iPhone, Android, Mac и Windows и ставится на домашний экран как обычное приложение.

- **GitHub Pages** отдаёт сам сайт: `index.html`, `app.js`, `style.css`.
- **Supabase** (бесплатный тариф) отвечает за аккаунты, базу сообщений, мгновенную доставку (Realtime) и аватарки.

Что уже работает: регистрация и вход по почте и паролю, поиск людей по ID и имени, личные чаты, мгновенная доставка, статус «в сети / был(а) в …», «печатает…», галочки ✓/✓✓, счётчик непрочитанных, аватарки, светлая и тёмная тема, уведомления, пока приложение открыто.

---

## Шаг 1. Supabase (≈5 минут)

1. Зайди на <https://supabase.com>, нажми **Start your project**, войди через GitHub и создай **New project**. Регион выбери ближе к России, например *Central EU (Frankfurt)*. Пароль базы сохрани где-нибудь, но в код его не вставляй.
2. Когда проект создастся, открой **SQL Editor → New query**, вставь **весь** файл `supabase/schema.sql` и нажми **Run**. Внизу должна появиться строка *«Йетя: схема установлена ✓»*. Если вместо неё ошибка, значит, скрипт откатился целиком и в базе ничего не создалось. Пришли текст ошибки.
   Потом в новой вкладке запроса выполни `supabase/storage.sql`: он настраивает аватарки.
3. Открой **Authentication → Sign In / Providers → Email**:
   - для тестов проще **выключить «Confirm email»**: тогда вход сразу, без письма. Встроенная почта Supabase отправляет всего пару писем в час.
   - если подтверждение оставишь, то в **Authentication → URL Configuration** укажи в *Site URL* адрес сайта из шага 3 (`https://savilovskis.github.io/yetya/`).
4. Открой **Project Settings → API** (или кнопку **Connect** сверху) и скопируй:
   - **Project URL**,
   - ключ **anon public** (может называться *publishable*).
5. Вставь оба значения в `config.js`.

> Ключ `anon` можно публиковать: данные защищены правилами доступа (RLS) из `schema.sql`. Чужие переписки не видны, а отправить сообщение от чужого имени нельзя. Ключ **service_role / secret** никогда никуда не вставляй.

## Шаг 2. Проверить у себя на Mac (по желанию)

```bash
cd ~/Desktop/Проекты/Yetya/yetya-web
python3 -m http.server 8080
```

Открой <http://localhost:8080>. Чтобы проверить переписку, зарегистрируй два аккаунта: один в обычном окне, другой в приватном.

## Шаг 3. Выложить на GitHub Pages

1. На GitHub создай новый репозиторий **`yetya`** (Public) без README.
2. В Терминале:

```bash
cd ~/Desktop/Проекты/Yetya/yetya-web
git init
git add .
git commit -m "Йетя: веб-мессенджер"
git branch -M main
git remote add origin https://github.com/savilovskis/yetya.git
git push -u origin main
```

   Если Git просит пароль, нужен не пароль от GitHub, а *Personal access token*. Проще поставить **GitHub Desktop** и нажать *Publish repository*.
3. В репозитории открой **Settings → Pages → Build and deployment**: *Source* = **Deploy from a branch**, *Branch* = **main**, папка **/ (root)**, нажми **Save**.
4. Через 1–2 минуты сайт заработает по адресу **https://savilovskis.github.io/yetya/**.

После каждого изменения делай `git add . && git commit -m "..." && git push`. Если поменял файлы приложения, увеличь `CACHE = "yetya-v1"` в `sw.js` до `v2`, `v3` и так далее, чтобы у всех подтянулась новая версия.

## Как поставить на телефон

- **iPhone:** открой ссылку в Safari, нажми «Поделиться», затем «На экран Домой».
- **Android:** открой ссылку в Chrome, в меню ⋮ выбери «Установить приложение».

Чтобы позвать друга сразу в чат, отправь ему ссылку вида `https://savilovskis.github.io/yetya/#@твой_id`.

## Ограничения бесплатного варианта

- Если неделю никто не заходит, бесплатный проект Supabase **ставится на паузу**. Его включают кнопкой *Restore* в панели Supabase, данные при этом не пропадают.
- Из России Supabase иногда открывается только через VPN. Если появляется надпись «Нет связи с сервером», дело в этом.
- Уведомления приходят, только пока приложение или вкладка открыты (можно в фоне). Пуши на закрытое приложение требуют отдельного сервера, это следующий этап.
- Пока только личные чаты 1-на-1 и только текст. Группы, фото в сообщениях и голосовые можно добавить позже.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | разметка всех экранов |
| `style.css` | оформление (светлая и тёмная тема, телефон и компьютер) |
| `app.js` | логика: вход, чаты, отправка, realtime, профиль |
| `config.js` | адрес и ключ Supabase (заполнить!) |
| `sw.js`, `manifest.webmanifest`, `icons/` | чтобы приложение ставилось на экран и открывалось без браузерной рамки |
| `supabase/schema.sql` | таблицы, правила доступа и функции для базы |
| `supabase/storage.sql` | хранилище для аватарок |

## Частые ошибки

- **«Could not find the function public.username_available(u) in the schema cache»**: `schema.sql` не выполнился до конца. Запусти его ещё раз целиком и проверь, что внизу появилась строка «схема установлена ✓». Если строка есть, а ошибка осталась, выполни `notify pgrst, 'reload schema';` и подожди 10 секунд.
- **«Нет связи с сервером»**: Supabase недоступен из твоей сети, включи VPN.
